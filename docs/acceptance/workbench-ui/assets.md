# 素材关联与历史版本规格

来源：[分镜第1集第1段](https://reelbenchai.com/v1/p/4cbd73adcc15/storyboard/1/1)、[项目素材库](https://reelbenchai.com/v1/p/4cbd73adcc15/library)、[用户资产库](https://reelbenchai.com/v1/asset-library)。2026-10-12 实际打开选择器和历史面板；没有保存关联、生成或恢复素材。

## 两种引用范围

**操作观察**：镜头“加素材”打开右侧可调宽度选择器，标题“用在：第1镜”；段视频的“加素材”显示“用在：本段视频”。均按场景、角色、道具分组。组列表显示未引用/在用及选中视图；视频角色组另显示“+音频”。演示两个范围均显示当前3张、上限10；这是该界面的观察值，其他模型上限需能力表确定。

选择某组展示其各视图、当前选中、默认、过期、未出、使用建议以及详情链接。底部“从列表去掉”和“用默认（只发锚点）”不同：零张图组仍能留在列表；只有移除组才移除该引用组。完成按钮关闭面板，不能据此断言保存已成功；自动保存/提交时机未在只读演示验证。

| 引用 | 组/视图规则 | 网站可见条件 |
| --- | --- | --- |
| 角色 | 正面全身锚点、正脸大头照、90°侧面、背面、自定义派生 | 大头照用于多人同框稳脸；没出图不能选 |
| 场景 | 正面锚点、俯视、背面北向南、左侧西向东、右侧东向西 | 俯视只定位陈设；镜头机位西时左侧标“跟本镜机位同一侧” |
| 道具 | 正面锚点及其方向/状态图 | 具体视图来自实体，不套角色格式 |
| 过期已存在图 | 显示过期原因，仍可选/发送 | “还能发，但可能跟现在设定对不上” |
| 过期锚点的未出派生 | 派生生成按钮禁用 | 提示先在详情重出锚点 |

视频侧栏显示组所属实体详情链接、涉及的镜头编号、图序、用途备注、移除/加图、音频开关。备注声明会写入提示词。图序决定`Picture k`绑定，不能按实体名称排序改变上传次序。当前页未实际调整图序，排序持久化与提示词同步需本地验收。

## 音频

**操作观察与页面声明**：只在整段视频角色组出现音频选择与试听，图片选择器没有音频。与图分开勾选。演示角色音频10秒WAV。页面列出 Seedance 2.0、万相3.0以及参考图模式H3接收；上限通常3段，万相5段，总长15秒，超出按顺序截短。

这些是该工作台的规则声明，不替代供应商当前协议验证。能力表登记是否支持音频、段数/时长；任务快照保留选中版本、上传顺序、截短结果及理由。原音频不可被截短过程覆写，用户看到的发送稿/摘要应可核对最终使用时长。不能把角色有音频等同于所有模型都自动发送。

## 数据模型与保存（本仓库实现约定）

引用组以 `(project_id, scope_kind, scope_id, entity_kind, entity_id)` 识别；单镜scope和段scope分开。组顺序、用途备注、选择模式（默认锚点/显式列表/零图）保存独立字段；选图关联媒体版本ID与组内序号；视频音频关联单独保存。

引用实体和媒体必须同项目且匹配角色/场景/道具用途，禁止客户端传跨项目UUID或R2路径直接绑定。名称只是展示；改名不破坏关系。零图组不是默认回退，否则无法做到“一张不选但组还在”。默认组在准备任务时解析成具体版本，已排任务继续使用旧快照。

编辑单镜关联不影响段视频关联，反过来同样。刷新恢复保存内容；保存失败保留用户草稿并提示，不能关闭面板后丢失或谎报保存。并发编辑需要版本号/冲突处理，不能最后一个响应静默覆盖。机位建议不是自动替换依据，方向图不存在时需明确回退/缺失提示。

## 媒体历史

**操作观察**：镜头图历史面板显示“每次重新生成、编辑和恢复都会保留一个版本。恢复只切换当前图片，不会删除后来的版本”，演示没有其他版本。具体恢复请求未验证。

**实现约定**：对象内容寻址、版本只追加、当前指针与历史内容分离。恢复如果需要追加恢复事件/版本，保留其引用原版本，禁止复制逻辑误删较新版本。历史媒体有完整哈希、提示词、模型、风格快照及来源；当前风格改变仅标记适用性，历史文件继续存在。R2文件丢失、过期和等待执行器是三个维度，不能合成一个状态。

## 项目素材库与用户资产库

| 页面 | 实际观察 | 范围 |
| --- | --- | --- |
| 项目素材库 | 小说/图片/提示词/视频四类；本次1/17/0/0。小说有原文件名/大小/哈希/日期与下载；图片含实体种类、显示码、视图、大小、哈希。切换提示词显示“0条”；视频“还没有视频素材”与补齐按钮 | 项目使用及生成的实际素材、发送稿和历史媒体；不是角色卡模板库 |
| 用户资产库 | 全部/角色/场景/道具筛选、搜索、导入目标、打开项目；全局为空 | 项目之外的可复制角色/场景/道具副本 |

**操作观察**：取消目标项目后URL从`?project=P`变成无query，“打开项目”链接消失，全局库仍存在。选择目标只决定复制到哪里，不改变全局库归属。添加副本、复制导入后的新ID与版本独立性尚未实测。

**实现约定**：用户资产库复制建立目标项目新实体ID并保存来源；不要直接把另一个项目UUID用作外键。复制后修改不反向改源项目。缺目标禁用导入并引导选择。素材列表计数来自记录，不能用页脚磁盘大小估算数量；本次视频空状态页脚曾显示1KB，不应据此断言存在视频。

项目图片列表声明同时显示当前与被替换图；每次视频生成留版本、同段最新标“最新”。图片“一键生成全部”在演示禁用，视频“补齐”可见，但模型/权限/实际提交逻辑未验证。后续实现只补缺失时不能覆盖ready结果，失败与过期图的重新生成是明确不同请求。
