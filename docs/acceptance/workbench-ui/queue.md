## 本仓库的任务契约（实现约定）

任务与供应商任务是不同身份。至少包含：内部任务UUID、项目、用途（角色锚点/派生、场景/道具、镜头图、段视频）、目标实体稳定ID、前置任务、状态及原因、尝试编号、租约/心跳、供应商job/prompt ID、入队幂等键、时间、输出版本和错误摘要。

任务快照保存：输入语义指纹、显示稿、最终发送稿、协议版本、角色/场景/道具选用的媒体版本ID及顺序/备注、音频版本、解析后的模型/渠道与参数、项目风格/比例、衔接段输出版本。快照不能只保存“当前模型/当前图”的指针。不得保存凭据本体。

### 推荐状态与转换

这是设计，不是网站观察：`draft → preparing → queued → running → succeeded`；前置/确认/离线可以表示 `blocked` 加原因（dependency/anchor_confirmation/executor_offline）；执行失败 `failed`；取消请求 `cancel_requested → cancelled`。准备失败没有生成调用；重试新增attempt，保留失败与原始快照。M1的task_snapshots继续只有draft/contract_only，不提前把契约数据变成排队任务。

| 触发 | 要求 |
| --- | --- |
| 双击生成或网络重试 | 同一幂等请求只产生一个业务任务；用户明确重新生成使用新请求ID |
| 前置完成 | 固定该前置产出的版本，不在执行时偷偷换成更晚版本 |
| 锚点需确认 | 生成完成不等于确认；待确认派生任务不能被批量生成绕过 |
| 执行器离线 | 排队等待，只改变可执行性；已经ready的媒体仍可访问 |
| 重启时持有供应商任务ID | 查询/恢复同一上游任务，不重复付费提交 |
| 重启时提交结果不确定 | 标记需要核对，优先查供应商幂等/任务信息；不能直接假定未提交 |
| 取消排队任务 | 不发送供应商请求；依赖任务显示前置已取消及处理选项 |
| 取消正在执行 | 根据适配器能力请求取消；不支持时照实显示，晚到结果不自动覆盖当前媒体 |
| 回调/轮询重复完成 | D1输出版本与任务终态幂等；不能重复追加版本或把已取消任务恢复成成功 |
| 失败重试 | 保留上一attempt，明确沿用旧快照；按新设置重跑作为新任务，不把旧任务内容重写 |
| 批量部分失败 | 已成功输出保留；显示每个目标失败原因，只重试失败目标 |

持久化D1任务、Worker调度与本机执行器租约需相互协调；不能用内存数组或浏览器setInterval持有唯一队列状态。Cloudflare AI Gateway不承担这些职责。ComfyUI上游的排队是第二层，需要保留prompt ID和位置/状态，不能把我方“已提交”直接当“正在生成”。

## 页面与错误表现（实现约定）

队列显示项目/目标链接、用途、状态/等待原因、入队时间、当前attempt、模型摘要、结果或错误、可用操作。没有任务显示空状态；加载失败显示重试，不冒充空队列。操作请求中禁用重复按钮；成功后刷新保留状态。取消不可支持时明确禁用及原因。

提示词界面区分显示稿与实际发送稿。检查图序与占位符、镜头时间轴、对白和必备短语；翻译不能丢掉引用。没有配置文本模型或语义质量门失败应在准备阶段给出阻断原因，保留可修正草稿。不要为了演示而生成伪视频或把模拟测试任务标为真实模型生成。

并发、依赖与取消/重试属于M5验收，M1只定义能力与配置契约。真实调用验证需隔离测试项目和明确可用适配器；本规格不授权付费调用。
