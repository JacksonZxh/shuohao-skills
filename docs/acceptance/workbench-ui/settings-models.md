# 设置与模型交互规格

真相源：[项目设置](https://reelbenchai.com/v1/p/4cbd73adcc15/settings)、[模型与分配](https://reelbenchai.com/v1/settings/models)、[ComfyUI](https://reelbenchai.com/v1/settings/comfyui)、[画风](https://reelbenchai.com/v1/settings/styles)。日期 2026-10-12。保存和跨刷新持久化没有在只读演示中验证。

## 项目设置

页面有画面比例、模型、角色图、美术图四个锚点分区，以及整机设置链接。

| 设置 | 可见值/操作 | 范围与规则（页面声明） |
| --- | --- | --- |
| 图片和视频比例 | 16:9 横屏 / 9:16 竖屏；当前已选16:9 | 项目共同比例，任务入队时固定；后改不影响排队或已生成素材 |
| 文本模型 | 大纲/角色/美术/剧本/分镜文字与翻译 | 项目独立；新建时从整机默认复制；此后全局修改不传播 |
| 出图模型 | 分镜图 | 同上；新项目角色、美术锚点初值取它，之后各自独立 |
| 视频模型 | 分镜视频与整片合成 | 同上；可选模型来自整机启用渠道 |
| 角色锚点 | 正面全身模型 | 只作用角色 |
| 角色派生模型 | 大头照、侧面、背面、细节图；空选择“同锚点模型” | 跟随角色锚点，不跟随美术模型 |
| 美术锚点 | 场景正面及道具设定图 | 只作用美术 |
| 美术派生模型 | 场景俯视、背面、左侧、右侧 | 空选择跟随美术锚点 |
| 锚点出完先确认 | 复选框，演示未选 | 角色与场景共用；确认后才派生。页面没有明确道具采用同样确认流程，不能直接推断 |

**操作观察**：文本/出图/视频/锚点模型选择器因没有模型而禁用；角色和美术派生选择器可展开，只有“同锚点模型”。不要显示错误的可调用默认模型；禁用同时给出原因和整机设置入口。

**实现约定**：保存项目路由与全局默认分离；不能靠每次渲染读取全局值模拟“新建时复制”。派生跟随使用显式回退规则，不将它物化成永远不变的旧锚点型号。入队时解析有效模型并生成不可变任务快照。

## 整机模型路由

三种主要能力文本/出图/视频都必须指定。缺少时分别显示当前哪类工作不可运行。出图另有“备选”，页面声明给角色派生图初值使用。启用的渠道模型才进入选择器。

### 新增渠道

**操作观察**：点击“新增渠道”打开“接一个新的上游”面板；关闭、取消、保存渠道按钮可见。切换方式即时改变字段。没有保存任何渠道。

| 接入方式 | 字段 | 原网站表单说明 |
| --- | --- | --- |
| OpenAI 兼容/中转站 | 名字、地址、API Key、额外请求头；请求头可加一行/删除该行 | 文本 `/chat/completions`，图像 `/images/generations`；地址带 `/v1`，不带完整方法路径 |
| 本机 codex | 名字；地址和 Key 隐藏 | 本机登录态；图像经 imagegen 微服务，文本经 `/text` |
| Anthropic 官方 | 名字、可空地址、API Key | 留空地址使用官方端点；页面声明 `/v1/messages`、effort/thinking、不使用 temperature |
| 自部署 ComfyUI | 名字、地址、Basic Auth 用户名/密码、备用隧道地址、优先隧道复选框 | 地址到 host:port；备用地址是同一台机器另一条路 |

Key/密码的页面语义是“留空不改动已存的”，不能将编辑时空输入理解成清除。明确清除凭据必须单独动作；响应只给是否配置，不回显。类型切换后隐藏的旧凭据不能发送到新类型，也不能残留到前端日志。

模型新增/编辑/删除、启用开关、连接测试、模型列表发现和保存错误没有现成渠道可供演示验证。实现时提供列表空状态、请求中、失败重试、保存结果；不可仅布置按钮。API Key 是否必填取决于适配器，不能用同一全局必填规则限制无 Key 的本机/Ollama场景。

### 本仓库的云端接入边界（实现约定）

Cloudflare AI Gateway 是受支持上游的统一调用出口，渠道类型与协议能力仍分别登记；网关不替代模型路由、任务队列或协议适配。不能因填写渠道就显示“已连通”。M1 只做配置契约与快照，实际调用在后续阶段。

本机 Codex 和局域网 ComfyUI 由本机执行器访问，浏览器不直接请求本机端口，Worker 也不假定能访问用户的 localhost。公网 ComfyUI 是否走网关需独立确认协议支持，不能伪造网关渠道。离线只影响相关生成，不影响已生成媒体读取或文稿编辑。

Cloudflare secrets 保存远程凭据；D1 仅存凭据引用和非秘密路由数据。本机连接凭据由执行器管理。新增渠道、编辑凭据和写入设置需要鉴权，读取不能泄漏凭据。技术存储细节放实施文档，不作为用户流程里的多余步骤。

## ComfyUI 默认参数

地址、备用地址、用户名、密码状态、优先备用地址；“测试连接”和“保存”分开。H3 默认值：分辨率0.6百万像素、帧率24、种子留空随机、上下文长度5、音频上下文3、turbo已选。这组是服务器默认，不能与每段可覆盖参数混成一层。

**操作观察**：地址空时两个按钮禁用并提示“要填 ComfyUI 地址”。输入 `not-an-address` 后提示“地址要带上 http:// 或 https://”；测试连接变为可点击、保存仍禁用。这个差异必须保留在观察记录里，不能声称网站对非法地址禁用了两个按钮。我们的服务端测试和保存都要做语义校验，防止无效地址进入请求路径。

端口/备用隧道失效属于连接错误。测试连接不能顺带发生成任务。请求超时、认证失败、连接失效各需可读原因；测试结果绑定本次连接配置，修改地址后旧成功状态失效。

## 画风管理与模型设置的不同回退

**页面声明**：未单独选画风的剧目沿用全局默认，项目自己选择优先。这与项目模型“初始化时复制，之后独立”不同，不能把所有设置做成同一种继承机制。全局设为默认只影响之后提交的生图任务，不改写已有提示词或替换旧图。

画风列表包含六张卡；可点击详情、设为默认、新建（从当前默认复制）及拖动排序。详情包含封面（建议16:9）、顺序、名字、分类、说明、标签、四个维度、提示词、历史版本和保存/删除。分类仅分组，题材世界只用于推荐和归类；修改维度不自动覆盖手写提示词，需“重新生成提示词”→确认→保存。

**操作观察**：真人实拍详情的提示词及出厂版本在演示中显示0字，没有获得实际正文，不能复制空字符串当作完整出厂风格。

**页面声明的分段规则**：`[Characters]`/`[Avoid in characters]` 只给人物图，`[Scenes]` 只给场景图，`[Props]` 只给道具图，其余和自加分段所有图携带；分镜图包含全部。Qwen文生图的 `[Avoid…]` 行转入负面提示词，这是网站工作流声明，不是所有供应商的通用规则。

**实现约定**：项目风格版本、用途层和模型负面提示词能力分离。任务快照保存最终展开文本与版本；旧媒体保持旧look/style快照。换默认不导致旧图消失；改变图像依据触发过期判定。版本保存、恢复、依赖提示与删除限制需本地实测；界面不能将仍被任务/媒体引用的版本硬删除。

## 其他设置页面与云端差异

| 页面 | 网站可见功能 | 本仓库实现与验收要求 |
| --- | --- | --- |
| 存储目录 | 图片/视频路径、文件数、保存；说明默认`.reelbench/`，更改会搬迁；演示空路径提示不能为空 | 云端素材在R2，不能假造Worker本机目录搬迁。若保留本机缓存设置，明确属于执行器且由执行器处理；云端存储状态显示实际绑定与统计 |
| 本机环境 | 前端/后端/生成worker/接口版本、检测/复制版本、隐藏路径地址；演示worker没运行 | 区分网站服务和本机执行器。显示我们自己的版本；0/0依赖不是全部就绪；缺单个能力不阻断无关功能 |
| 内容更新 | 更新源、验签公钥、检查内容；声明签名不符拒绝，本地定制只提示新出厂版本 | 没有实际包与验签协议，不得声称更新已实现；需签名失败与保留本地定制测试后启用 |
| 模型试运行 | 中译英/英译中、输入、必备短语、禁止角色名、结果；检查耗时/token/质量门 | 当前无模型未调用。检查英文夹中文、短语、禁止名字；视频正文可以有人名，不能误用设定图规则 |
| 系统提示词/调用日志 | 导航存在；上轮观察正文为空 | 仍是未验证页面，实施者需实测可用环境再确定正文结构；不能写成完整已复刻 |
