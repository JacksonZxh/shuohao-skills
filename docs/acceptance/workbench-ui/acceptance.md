# 页面与交互验收矩阵

测试使用合成项目A/B、可控模拟供应商、本机执行器测试实例、隔离D1/R2。页面对照原网站，后台正确性依据以下实现约定。当前这里只交付用例，不声称它们已在工作台实现或运行。

## 设置和模型

| 编号 | 操作 | 预期与必查数据 |
| --- | --- | --- |
| UI-S01 | 全局默认M1新建A；全局改M2再新建B | A仍M1，B为M2，刷新持久；后台记录相互独立 |
| UI-S02 | 只改A角色锚点；派生设置跟随 | A角色派生使用新锚点模型；美术与分镜图不变 |
| UI-S03 | 设置显式角色派生M3，再改锚点 | 角色派生仍M3；取消显式选择后回退 |
| UI-S04 | A设置比例16:9排任务，再改9:16 | 旧任务快照16:9，新任务9:16；旧素材不变 |
| UI-S05 | 空模型/禁用渠道/删已选择模型 | 显示缺失或不可用原因，禁止相应新任务；历史输出继续读取；禁止静默换型号 |
| UI-S06 | 渠道新增面板依次切换四类型 | 字段如规格；取消不创建；隐藏字段不提交；空输入不清除旧凭据 |
| UI-S07 | 错误地址、401、超时、模型列表失败 | 服务端校验与可读错误；保存不冒充连通；连接测试不生成任务 |
| UI-S08 | 未认证写配置、读取已配置Key | 写入拒绝；读取仅是否配置；前端/错误/日志无秘密 |
| UI-S09 | A画风未单选，B显式选；修改全局默认 | A后续任务使用新默认，B不变，旧任务保持旧版本；与模型复制规则区别明确 |
| UI-S10 | 修改画风维度，再查看手写提示词 | 提示词不自动覆盖；重写需确认；按用途分段展开，未知分段保留 |
| UI-S11 | 换项目风格，读取旧媒体/历史版本 | 历史快照不变；适用性过期不等于文件缺失；当前指针保持合法 |
| UI-S12 | 执行器离线，打开文稿与旧媒体 | 无关功能可用；本机任务明确等待；环境0/0不显示全部就绪 |

## 素材关联与素材库

| 编号 | 操作 | 预期与必查数据 |
| --- | --- | --- |
| UI-A01 | 第1镜选图，段视频选另一组 | 两范围独立；编辑/刷新只影响目标scope |
| UI-A02 | 组多选/零选/移除/用默认 | 零选不发送图但保留组；移除清除组；默认仅锚点，不能混淆 |
| UI-A03 | 选图超过模型限制 | 前后端都校验，计数按实际图片不是组数；错误不破坏已保存关系 |
| UI-A04 | 选不存在派生图、选过期已有图、点过期锚点派生生成 | 不存在不能选；过期可发送并警示；派生生成被阻止，缺失与过期分别显示 |
| UI-A05 | 图排序+备注后准备发送稿 | Picture序号/上传顺序/引用说明一致；任务快照保存最终版本及序号 |
| UI-A06 | 仅视频角色组选音频；超段数或15秒 | 图片任务无音频；模型能力限制生效；按顺序截短的结果可核对、原文件不变 |
| UI-A07 | 引用另项目实体/媒体UUID | 后端拒绝且零关系写入，不能只靠选择器过滤 |
| UI-A08 | 改名、重排、保存后刷新 | 稳定ID关系不变；失败保留草稿；并发冲突不会静默覆盖 |
| UI-A09 | 连续生成v1/v2，恢复v1 | 当前显示恢复结果；v2仍可访问；任务/风格/提示词溯源不变 |
| UI-A10 | 两个用户/项目素材库过滤 | 列表权限隔离，加载失败与空状态不同；图片历史与视频最新标记准确 |
| UI-A11 | 用户资产复制到B，再改B | 新UUID及来源记录，A/全局副本不被改写；不选择目标时禁止导入 |

## 队列与提示词

| 编号 | 操作 | 预期与必查数据 |
| --- | --- | --- |
| UI-Q01 | 同一幂等请求双击/重传，批量补缺失 | 一个业务任务/目标；不重做已有ready媒体 |
| UI-Q02 | 队列参数改动、关页、重启 | 已排快照不变，任务持久，重启恢复而非丢弃 |
| UI-Q03 | 提交供应商后进程崩溃、完成重复回调 | 使用保存的上游ID恢复，避免重复付费；一个最终输出版本 |
| UI-Q04 | 前置依赖与锚点待确认 | 未完成/未确认不能执行后续；父任务取消/失败有明确原因 |
| UI-Q05 | ComfyUI同机多视频+图片、不同渠道任务 | 同机资源限制生效，不等同于全局并发；不同渠道不被错误一起阻塞 |
| UI-Q06 | 取消queued/running、晚到完成 | queued不提交；running按能力取消；晚到结果不误覆盖当前媒体 |
| UI-Q07 | 一个批量失败、重试、按新配置重做 | 成功保持；失败attempt可追溯；重试沿用旧快照，新配置作为新任务 |
| UI-Q08 | 翻译失败或丢图序/对白/时间轴 | 准备阶段阻断，无生成调用；保留草稿与可定位质量门错误 |
| UI-Q09 | 无任务、队列加载失败、供应商不可用 | 三种状态分别呈现，不把失败显示成空队列或成功 |

## 验收归属与剩余空白

PR2采用[19项独立数据案例](../pr2/cases.json)，尤其稳定ID、项目范围、未知字段、鉴权与事务。模型路由/任务快照先在M1后续契约PR落形状；UI-S完整页面按前端里程碑实施；媒体和风格UI-A基础在PR4验收；镜头/段引用随分镜页面；队列UI-Q在M5验收。不因增加本文而扩大当前PR2到付费生成或完整前端。

仍未从只读站得到：真实队列列表布局/状态、模型已配置时的编辑与探测、保存失败响应、引用保存时机、历史版本恢复、复制资产结果、系统提示词/日志正文。Grok在可操作实例验证后应补充来源和差异；若原网站仍不可验证，采用这里明确的实现约定并标记，不能宣称已经按原网站实测。
